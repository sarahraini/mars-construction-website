# MARS Construction Website

## Project Overview

A professional business website developed for an Australian construction company.

The website was designed to establish an online presence, showcase construction services, and improve customer enquiries.

## Live Website

https://www.marsconstructionservices.com.au

## Technologies Used

- WordPress
- Elementor Page Builder
- Astra Theme
- HTML5
- CSS3
- JavaScript
- SEO Optimization
- Responsive Web Design

## My Role

WordPress Developer

Responsibilities:

- Website design and development
- Theme customization
- Page layout creation
- Mobile responsiveness optimization
- Contact form integration
- Basic SEO configuration
- Performance optimization

## Features

✅ Modern construction company website
